## Project Overview
TOEIC Mentor is an intelligent learning assistant designed to help users prepare for the TOEIC (Test of English for International Communication) exam. The application provides comprehensive TOEIC preparation tools including practice tests, personalized feedback, and AI-powered assistance.

## Features

### AI-Powered Learning Assistant
- Interactive chat interface with a specialized TOEIC preparation AI assistant
- Personalized responses to questions about TOEIC vocabulary, grammar, test strategies, and exam structure
- Conversation history management and rating system for responses

### TOEIC Practice Tests
- Full-length TOEIC practice tests with all 7 parts of the exam
- Question categorization by difficulty level
- Timed test-taking experience simulating real exam conditions

### Test Analysis & Performance Tracking
- Detailed test result analysis including scores and performance metrics
- Comprehensive explanations for all answer options (correct and incorrect)
- Personalized recommendations for improvement based on test results
- Performance tracking to monitor progress over time

### Additional Tools
- PDF generation for test results and performance reports
- User account management with role-based access control
- Mobile-responsive design for learning on any device

## Technical Stack
- **Backend**: Java with Spring Boot framework
- **Frontend**: HTML, CSS (with Tailwind CSS), JavaScript
- **Database**: JPA/Hibernate (SQL database)
- **Authentication**: Spring Security
- **AI Integration**: Custom AI implementation with chat memory and feedback systems
- **Testing**: JUnit for unit tests

## Getting Started
1. Clone the repository
2. Configure your database connection in `application.properties`
3. Run the application using Maven: `mvn spring-boot:run`
4. Access the application at `http://localhost:8080`
